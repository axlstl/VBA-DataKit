# VBA-DataKit

A lightweight VBA library for data manipulation in Excel.

I originally developed this library at the beginning of a trading internship to automate repetitive data processing tasks that had to be performed in VBA.

What started as a few utility functions gradually evolved into a collection of tools for filtering, sorting, grouping, and manipulating arrays, inspired by pandas and NumPy.

## Documentation

**[VBA-DataKit Documentation](https://axel.sottile.fr/vba/)**

## Installation

Make sure to enable the **Microsoft Scripting Runtime** reference in the VBA Editor (*Tools → References*).
You can then add the files to your VBA project in two ways:
- **Drag and drop** the files directly into the VBA Editor with your workbook (+ VBA-DataKit) opened (fastest method).
- **Import** the files one by one using *File → Import File* (takes a bit longer).
